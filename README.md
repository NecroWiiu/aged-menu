# Aged Menu (Fabric 1.20.1, Java 17)

Reemplaza la pantalla de título por una con fondo pixel-art, botones minimalistas y transiciones suaves.
Botones: Un jugador, Multijugador, Mods (Mod Menu), Opciones, Salir, Idioma y Accesibilidad.
Solo cliente, sin dependencias (Fabric API opcional). Mod Menu se detecta por reflexión.

## Compilar
Con JDK 17 y Gradle 8.8+:  `gradle build`  ->  `build/libs/aged-menu-1.0.0.jar`
(o sube la carpeta a GitHub: el workflow de Actions compila y te da el .jar).
